# Biblioteca IPF

Trabajo Práctico N° 4 — Taller Complementario React Native II (IPF).
Alumno: **Galban Rojas, Leonel**.

App para consultar el catálogo de la biblioteca, reservar libros, recibir un recordatorio
de devolución y, para el personal, entregar libros respetando el orden de las reservas.

## Versión

- **Expo SDK 58** (`expo ~58.0.26`, `expo-router ~58.0.32`, React Native 0.88).
- Proyecto creado con `npx create-expo-app@latest` (TypeScript + Expo Router).

## Cómo ejecutar

```bash
npm install
npx expo start
```

Escanear el QR con Expo Go (el teléfono y la computadora en la misma red Wi-Fi).
